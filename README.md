# Live Interior

Premium interior design studio website — **Live Interior**, Ghaziabad.

A fully responsive, interactive single-page website showcasing interior design
services, portfolio and contact details.

## ✨ Features

- Animated preloader, custom cursor & scroll progress bar
- Sticky navbar with animated mobile menu
- Hero section with parallax background & animated stat counters
- Services grid, 4-step process & auto-rotating testimonials
- Filterable portfolio gallery with full-screen lightbox
- Smart contact form that sends enquiries straight to WhatsApp
- Floating WhatsApp button

## 🛠️ Built With

- HTML5
- CSS3 (custom properties, grid, flexbox, animations)
- Vanilla JavaScript (no frameworks)

## 📂 Structure

```
liveinterior/
├── index.html      # Page markup
├── styles.css      # All styling
├── script.js       # Interactivity
└── images/         # Project photographs
```

## 🚀 Run Locally

Just open `index.html` in any modern browser — no build step required.
